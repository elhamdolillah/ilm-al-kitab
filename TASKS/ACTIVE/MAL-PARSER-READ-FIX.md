# MAL-PARSER-READ-FIX — إزالة الاستهلاك المزدوج لتوكن `⊙`

## الحالة

`PROVEN_FOR_SCOPE`

## التغيير

أزيل `self.bump()` الإضافي من ذراع `TokenKind::Read` في `parse_primary`. التوكن كان قد استُهلك بالفعل عند بداية الدالة؛ الاستهلاك الثاني كان يسبب `UnexpectedEof` عند تحليل `⊙`.

## نطاق الإثبات

- Parser: 35/35 اختباراً ناجحاً.
- اختبارات Read المستهدفة: 3/3 ناجحة.
- Lexer: 9/9 اختبارات ناجحة.
- Arena: 7/7 اختبارات ناجحة، بما فيها اختبار 10K.
- بصمة stdout محفوظة في `evidence/MAL-PARSER-READ-FIX.sha256`.

## القيود

هذا الإثبات يخص الحالة الحالية للكود واختبارات Rust المذكورة فقط. لا يثبت صحة كل MAL أو runtime أو التكاملات الخارجية. ظهر تحذير Rust غير مانع بسبب متغير `right` غير مستخدم في اختبار قائم؛ لم يُعالج في هذه المهمة لأنه خارج نطاق إصلاح Read.

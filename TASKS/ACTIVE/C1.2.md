## التعريف الرياضي`\المجموعة A: كائن رياضي يحتوي على عناصر مميزة\العمليات:
  A ∪ B = {x | x ∈ A أو x ∈ B}       (union)
  A ∩ B = {x | x ∈ A و x ∈ B}        (intersection)
  A \ B = {x | x ∈ A و x ∉ B}        (difference)
  A Δ B = (A \ B) ∪ (B \ A)          (symmetric difference)
  A × B = {(a,b) | a ∈ A و b ∈ B}    (cartesian product)
  A ⊆ B ⟺ ∀x ∈ A, x ∈ B              (subset)
  A ⊇ B ⟺ ∀x ∈ B, x ∈ A              (superset)```

## النطاق\العمليات المسموح بها: ∪, ∩, \, Δ, ×, ⊆, ⊇\العناصر: أعداد صحيحة فقط (في هذه المرحلة)```

# MAL-INTEROP-C2 — Complementary Notation Equivalence\ن\ن## الحالة\ن`PROVEN_FOR_SCOPE`\ن\ن## الهدف\نإثبات أن الكتابات الجديدة (⎕, ⊕, ⊙) مكافئة دلاليًا للكتابات القديمة (اطبع, جمع, اقرأ).\نهذا يثبت أن الجديد هو "كتابة مكملة" وليس "إعادة اختراع".\ن\ن## التعريف الرياضي\ن```\نلكل عملية دلالية O:\ن  ∃ تمثيلان نصيان: T_old و T_new\ن  بحيث:\ن    eval(T_old, inputs) ≡ eval(T_new, inputs)
    ∀ inputs ∈ domain(O)\ن```\ن\ن## النطاق\نالكتابات المسموح بها:\ن```\ن⎕ ↔ اطبع  (طباعة)\ن⊕ ↔ جمع  (جمع)\ن⊙ ↔ اقرأ  (قراءة)\ن```\ن\ن## خارج النطاق\ن```\نالـ 13 عملية التي تفشل في math_complete.py\نUORI/UORI+ (لم تُنقل بعد)\نأي تعديل على Parser أو Compiler الحاليين\ن```\ن\ن## العقد\ن- كل زوج (كتابة قديمة, كتابة جديدة) يُنتج نفس المخرجات\ن- نفس الحالة الجانبية (stdout, exit code, flags)\ن- نفس الأخطاء (إذا كانت)\ن- fail-closed: عدم التكافؤ يُبلغ كخطأ صريح\ن\ن## معايير القبول\ن- 3 أزواج كتابات مثبتة التكافؤ\ن- نفس المدخلات → نفس المخرجات\ن- نفس الأخطاء\ن- stdout خام وexit code وSHA-256\ن- عدم تغيير MAL Parser أو Compiler\ن\ن## قرار السلامة\نلا يُعدَّل Parser أو Compiler في هذه المرحلة.\نالتكافؤ يُثبت في نموذج بحثي مستقل فقط.\ن
